# WORKBENCH_GUIDE — 学习工作台使用说明

> 面向使用者的完整操作手册。启动方式见下，所有功能都在一个网页应用里。

## 1. 启动与退出

**启动**：双击项目根目录的 `启动工作台.bat`。脚本会自动完成：

1. 定位项目目录（不依赖当前工作目录）；
2. 检查 JDK 17（优先使用 `tools/` 内置便携版）；
3. 检查编译产物（首次运行会自动用 Maven 编译）；
4. 检查端口 8642 占用（若工作台已在运行则直接打开浏览器）；
5. 启动本地服务（仅监听 127.0.0.1，不暴露到局域网）；
6. 健康检查通过后自动打开浏览器进入学习中心。

**退出**：关闭任务栏中标题为 "JavaDS-Lab 工作台" 的最小化窗口即可停止服务；启动脚本的窗口可以随时关闭。

**旧入口变化**：`启动播放器.bat` 已转为转发到工作台（独立播放器已整合进"数据实验场"）；`错题本.bat`（CLI）与 `运行测试.bat` 保留，与网页版共用同一数据库。

## 3. 推荐学习闭环

围绕任意知识点（例如"快速排序"）：

1. **看笔记**：`学习笔记 → 19-sorting`，或从实验场点"查看原理"；
2. **做练习**：笔记页点"去做练习"→ 写下自己的答案 → 点"查看参考答案" → 自评（不会/模糊/掌握）；
3. **做实验**：练习页点"去实验验证"→ 实验场自动选中该算法 → 填入数据执行 → 观察 Result 与 Trace 回放 → 点"查看 Java 源码"对照实现；
4. **记错题**：作答不理想时点"加入错题本"，选择错误原因；
5. **重做复习**：错题本中点"重新做"→ 先作答再看答案 → 如实标记"仍不会/基本理解/重做成功"（只有"重做成功"才累计成功次数）；
6. **管理状态**：复习地图中把知识点标为"未学/复习中/已掌握"——状态完全由你决定，系统不会自动推断。

## 4. 数据实验场

- **功能目录**：左侧按分类列出全部 44 个功能（数量来自功能目录实时读取）；支持搜索；带 `T` 标记表示支持 Trace 回放。
- **输入**：每个算法有专属表单（数组 / 目标值 / 文本+模式串 / 图边表 / DP 参数 / 结构操作序列），可用样例一键起步。
- **校验**：前端与服务端双重校验；二分查找会明确提示"该算法要求输入数组已经升序排列"，不会悄悄自动排序。
- **Result 模式 / Trace 模式**：所有算法都能跑出真实结果；44 个功能全部有 Trace 回放。输入规模过大时自动跳过 Trace（仅结果模式），并明确提示。
- **耗时说明**：结果面板区分"算法执行耗时"与"Trace 记录耗时"，Trace 开销不混入算法性能。
- **播放器**：⏮ 上一步 ◀ / ▶ 播放暂停 / 下一步 ▶ / ⏭，进度滑杆任意跳步，速度 0.5×~4×，缩略步骤条点击跳步，支持 JSON 导入/导出；键盘 ←/→/空格（在输入框打字时不触发）。
- **实验历史**：每次运行保存输入/结果/Trace/耗时/来源，可"重新打开"复现；运行链接可复制分享。
- **源码查看**：一键查看该算法的真实 Java 源码（仅限项目内白名单目录）。

## 5. 数据库实验

- **学习库 `data/lab.db`**（只读）：10 条固定复杂查询，展示 SQL、参数、真实结果、耗时与 EXPLAIN QUERY PLAN。
- **实验库 `data/experiment.db`**（独立文件，可写）：造数（最多千万行）、建/删索引、EXPLAIN、受限自由 SQL（单条；禁 ATTACH/PRAGMA/触碰学习库）。实验库的任何操作都不会修改学习库。
- 表关系与表结构直接读取 `sql/ER.md` 与 `sql/schema.sql` 原文。

## 6. 项目验证

- **本次执行**：Maven 全量测试 / 数据库性能实验 / 完整验证（测试 + 44 个 Trace 校验）以后台任务运行，不阻塞页面，实时显示阶段与日志。
- **历史报告**：JDBC 基准报告等来自项目已有文件，明确标注为历史数据，不会冒充"刚刚执行的结果"。

## 8. 常见问题

- **页面顶部出现"学习工作台服务已断开"**：服务已停止或端口变化。点击"重新连接"刷新页面；确认服务进程存在后重试。
- **双击 BAT 闪退/提示未检测到 JDK**：确认 `tools/jdk-17.0.20.1+1/bin/java.exe` 存在，或安装 JDK 17 并加入 PATH。
- **端口被占用**：编辑 `启动工作台.bat` 中的 `PORT` 变量（8642 → 其他）。
- **首次编译很慢**：Maven 需要下载依赖（sqlite-jdbc、junit），完成后离线可用；本工作台运行期完全不依赖网络。
- **实验数据想清空**：错题/练习/学习状态在"错题本"和"复习地图"逐条管理；实验历史可通过删除 `data/lab.db` 中 experiment_run 表数据清理（不影响 CLI 错题数据）。
