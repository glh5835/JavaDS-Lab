> 组织方式：按**知识依赖关系**分层——下层是上层的地基，复习必须自底向上。

## 推荐复习顺序（两条线）

1. **自底向上（结构线，适合期中）**：
   数组/链表 → 栈/队列 → 哈希 → 二分 → BST → 堆 → 遍历 → 排序表。
2. **算法思想线（适合期末）**：
   分治（归并/快排）→ 贪心（Dijkstra/Prim/Kruskal）→ DFS/BFS → 拓扑序 → DP 四步法刷 15 题 → KMP。
