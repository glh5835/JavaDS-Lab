# JavaDS-Lab 使用说明

> 面向使用者的完整操作手册。5 分钟跑起来，10 分钟玩转全部功能。
> 项目结构速览见 [README.md](../README.md)；算法原理见 [notes/](notes/)；复习规划见 [期末复习图谱.md](期末复习图谱.md)。

---

## 0. 环境准备（三选一）

本项目所有数据结构都是手写代码，**运行只需要 JDK 17 和 Maven**（可选 Python 用于本地网页服务）。

- **方式 A（推荐，零安装）**：项目自带便携版工具，仓库的 `tools/` 目录里已有
  JDK 17（Temurin）+ Maven 3.9.16。打开 Git Bash 执行：
  ```bash
  cd /d/JavaDS-Lab
  source tools/env.sh        # 激活 JDK/Maven（每次开新终端都要先执行）
  java -version              # 应显示 17.0.20.1
  ```
- **方式 B**：本机已装 JDK 17 + Maven，直接 `java -version` / `mvn -version` 确认可用。
- **方式 C**：用 IDEA / VS Code 打开项目根目录（Maven 项目会自动识别）。

> 注意：方式 A 下所有 mvn 命令都要加镜像参数：`mvn -s tools/maven-settings.xml ...`

## 1. 跑测试（验证一切正常）

```bash
mvn -s tools/maven-settings.xml test
```

预期最后两行：

```
Tests run: 161, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```

161 个测试覆盖：正常路径 / 边界（空表、单元素、回绕）/ 异常（越界、空弹、非法参数）/
大规模随机对照（手写结构与 JDK 容器对拍 2~5 万次随机操作）。

只跑某一组测试：

```bash
mvn -s tools/maven-settings.xml test -Dtest=SearchTreesTest      # BST/AVL/红黑树/B树
mvn -s tools/maven-settings.xml test -Dtest=PersistIntegrationTest  # SQLite 集成
```

## 2. 打开可视化播放器（最简单：双击）

**直接双击项目根目录的 `启动播放器.bat`**（或手动用浏览器打开 `web/player.html`）。
它内置了全部 44 个 trace，无需任何服务器。

想要本地服务器方式（可以加载 `trace/` 下的单个 JSON 文件）：

```bash
python -m http.server 8765        # 在项目根目录执行；需要本机有 Python
# 浏览器打开 http://127.0.0.1:8765/web/player.html
```

### 播放器操作

| 操作 | 方式 |
|---|---|
| 选择算法 | 顶部下拉框（44 个 trace：数据结构/图算法/排序/查找/DP） |
| 单步前进 / 回退 | 「下一步 ▶」「◀ 上一步」按钮，或键盘 ← / → |
| 自动播放 / 暂停 | 「▶ 播放」按钮或空格键 |
| 变速 | 右侧速度下拉（0.5× / 1× / 2× / 4×） |
| 任意跳步 | 拖动进度条 |
| 加载本地 JSON | 顶部「从本地 JSON 加载」选 `trace/*.json` 任意文件 |

画面下方的 `op` 标签是当前操作类型，后跟参数（比较的两个下标、交换值、松弛的边等）；
图例说明颜色含义：黄=比较、橙=交换、紫=基准、绿=完成/最短、红=当前活跃。

**推荐的 5 个演示**：`red-black-tree`（变色旋转）、`dijkstra`（d 值逐点定居）、
`sort-quick`（分区扫描）、`btree`（节点分裂）、`dp-knapsack`（背包表逐格填）。

## 3. 浏览 trace 文件（程序视角）

`trace/` 目录每个算法至少 1 个 JSON，格式：

```json
{ "meta": { "kind": "tree", "title": "红黑树（变色与旋转）", ... },
  "steps": [ { "i": 0, "op": "insert", "args": {...},
               "before": <快照>, "after": <快照>, "hl": {...} }, ... ] }
```

重新生成（改了源码或想刷新演示数据后）：

```bash
mvn -s tools/maven-settings.xml compile -q
java -cp target/classes com.javadslab.app.TraceGenerator /d/JavaDS-Lab
# 输出：trace/*.json + web/traces-bundle.js + trace/manifest.json
```

## 4. 数据库实验（模块四）

建库 + 造 10 万条数据 + 10 条复杂查询 + EXPLAIN 索引对比，一键重跑：

```bash
source tools/env.sh
J1=$(cygpath -w ~/.m2/repository/org/xerial/sqlite-jdbc/3.46.1.0/sqlite-jdbc-3.46.1.0.jar)
J2=$(cygpath -w ~/.m2/repository/org/slf4j/slf4j-api/1.7.36/slf4j-api-1.7.36.jar)
java -Dfile.encoding=UTF-8 -cp "target/classes;$J1;$J2" com.javadslab.app.QueryBenchmark .
# 结束后看 reports/jdbc-report.md（全部数字为当场实测）
```

- 表结构：[sql/schema.sql](../sql/schema.sql)（algorithms / runs / steps / mistakes，外键级联 + CHECK）
- 表关系图解：[sql/ER.md](../sql/ER.md)
- 数据库文件生成在 `data/lab.db`，可用任何 SQLite 工具打开
- 错题本 API（`com.javadslab.persist.Dao`）：
  `addMistake(算法id, 题目, 错误答案, 原因)` → `markRedo(错题id)` → `weaknessReport()` 按知识点统计薄弱项

## 6. 常见问题

| 现象 | 原因与解决 |
|---|---|
| `mvn: command not found` | 忘了 `source tools/env.sh` |
| Maven 下载依赖超时 | 没带 `-s tools/maven-settings.xml`（走了默认中央仓库） |
| `No suitable driver found for jdbc:sqlite` | 运行主类时 classpath 少了 sqlite-jdbc jar，或 jar 路径没转 Windows 格式（Git Bash 下必须 `cygpath -w`） |
| 播放器下拉框是空的 | 用 file:// 打开时必须保留 `web/traces-bundle.js` 与 player.html 同目录；或改用 http.server 方式 |
| javac 报「编码 GBK 的不可映射字符」 | 加 `-encoding UTF-8` |
| 想看某个结构的动画但列表里没有 | `trace/manifest.json` 是全部清单；没有的话说明该结构以快照嵌在别的 trace 里（如 Kruskal 内含并查集、Dijkstra 内含堆） |

```

├─ tools/            便携 JDK17 + Maven + 镜像配置 + env.sh（不入库）
├─ src/main/java/com/javadslab/
│   ├─ core/         模块一：linear/ stackqueue/ hash/ unionfind/ heap/ tree/ graph/ sort/ search/ dp/
│   ├─ trace/        模块二：Tracer、Json、可追踪排序/查找/DP/树遍历
│   ├─ persist/      模块四：Db 连接池、Dao、Queries、SeedData
│   └─ app/          TraceGenerator（生成 trace）、QueryBenchmark（生成报告）
├─ src/test/java/    161 个 JUnit 5 测试（含随机对照与集成测试）
├─ trace/            44 个算法 trace JSON + manifest
├─ web/              player.html 播放器 + traces-bundle.js
├─ sql/              schema.sql + ER.md
├─ reports/          jdbc-report.md 实测报告
└─ docs/             notes/ 22 篇笔记 + 期末复习图谱 + 本文档
```
