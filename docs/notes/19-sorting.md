# 十种排序

> 源码：`core/sort/SortingAlgorithms.java`（全部手写；对照 oracle 为同项目手写归并 `MergeSort`）

## 原理图解（核心 4 种）

```
冒泡：相邻比较交换，最大值“冒”到末尾      [5,2,9,1] → [2,5,1,9] → [2,1,5,9] → [1,2,5,9]
插入：像摸牌，key 前面的有序区整体右移    [5|2,9,1] → [2,5|9,1] → [2,5,9|1] → [1,2,5,9]
快排：选基准分区，小的左大的右，递归两侧  [5,2,9,1] → pivot=1 → [ ] 1 [2,9,5] → ...
归并：二分递归 + 线性合并两有序段        [5,2,9,1] → [5,2][9,1] → [2,5][1,9] → [1,2,5,9]

计数：值域桶计数后顺序写出                适合非负小值域
基数(LSD)：按个/十/百位稳定排序多轮        每轮用计数排序思想
桶排：值域均匀分桶 + 桶内插排
```

## 核心代码（基数排序的稳定性关键）

```java
for (int exp = 1; max / exp > 0; exp *= 10) {
    int[] cnt = new int[10];
    for (int v : a) cnt[(v / exp) % 10]++;
    for (int d = 1; d < 10; d++) cnt[d] += cnt[d - 1];   // 前缀和定位
    for (int i = a.length - 1; i >= 0; i--) {            // 逆序保证稳定！
        int d = (a[i] / exp) % 10;
        buf[--cnt[d]] = a[i];
    }
    System.arraycopy(buf, 0, a, 0, a.length);
}
```

## 复杂度推导要点

- 比较排序下界：n! 种排列 → 决策树高 ≥ log₂(n!) ≈ n log n（Stirling）→ **任何比较排序最坏 Ω(n log n)**。
- 计数/基数/桶是**非比较排序**，绕开下界，用值域/位数换时间。
- 归并 O(n log n) 恒定：T(n)=2T(n/2)+O(n)，主定理 case 2。
- 快排最坏 O(n²)：每次基准切出 1 和 n-1（有序+固定基准）；随机基准期望 O(n log n)。

## 易错点

1. 基数排序**必须逆序回写**（前缀和消耗式定位），正序会破坏低位已排好的次序。
2. 计数/基数教学实现只支持非负（本项目约定），负数要先偏移或分组。
3. 插入排序的 while 从 j=i-1 往左，写反了会死循环或错位。
4. 堆排建堆从 `n/2-1` 开始；排升序要用**大顶堆**（堆顶换到末尾）。
5. 桶排 `(v-min)*(buckets-1)/(max-min)` 注意 long 乘法防溢出。

## 练习题（附答案）

1. **排序稳定性排序后相等元素次序不变，举一个必须稳定的场景**
   答：多关键字排序（先按名字、再稳定按分数），或基数排序本身依赖低位稳定性。
2. **手推 [4,10,4,3,8,9] 一趟快排（基准=末尾 9）**
   答：小于 9 的依次交换到前区 → [4,4,3,8,10,9]，基准落位 10 前 → 结果 [4,4,3,8,9,10]，pivot=9 在 index 4。
3. **为什么堆排实际常慢于快排？**
   答：下沉访问数组下标跳跃（2i+1），缓存局部性差；快排分区顺序访问。
4. **希尔排序的一个增量序列及含义**
   答：n/2, n/4, ..., 1（Shell 序）：先让远距离大致有序，最后一轮插入排序在近有序数组上近似 O(n)。
5. **10 万个 0~9 的整数排序用什么最快？**
   答：计数排序 O(n+10)，一趟计数一趟写出，完胜任何比较排序。
