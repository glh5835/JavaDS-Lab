# 经典动态规划 15 题

> 源码：`core/dp/DynamicProgramming.java`（每题一个静态方法；测试与暴力递归对照）

## 通用方法论

```
DP 四步法：
①定义状态   dp[i] / dp[i][j] 的精确含义（含“恰好/至少/至多”措辞）
②状态转移   从子问题推当前（枚举最后一步/决策）
③初始化     边界即最小子问题
④遍历顺序   保证算 dp[x] 时依赖项已算好（一维看方向，二维看行列序）

一维滚动数组技巧：二维 dp 只依赖上一行 → 压缩为一行
0/1 背包逆序容量 / 完全背包正序容量 —— 本质是“本轮用过的值是否允许再取”
```

| 2 | 打家劫舍 | rob/skip | max(skip, rob+v) | O(n)/O(1) |

## 核心代码（0/1 背包 vs 完全背包：方向即语义）

```java
// 0/1 背包：容量逆序 → dp[c-w] 还是上一行的值，每件最多选一次
for (int i = 0; i < weights.length; i++)
    for (int c = cap; c >= weights[i]; c--)
        dp[c] = Math.max(dp[c], dp[c - weights[i]] + values[i]);

// 完全背包（零钱兑换 II 组合数）：容量正序 → 允许重复取
for (int c : coins)
    for (int x = c; x <= amount; x++)
        dp[x] += dp[x - c];        // 先物品后金额 = 组合数（不计顺序）
```

## 易错点

1. **背包方向**：0/1 逆序、完全正序，写反直接错（0/1 变无限取）。
2. “组合数 vs 排列数”：外层枚举物品=组合；外层枚举金额=排列（如爬楼梯本质是排列）。
3. 目标和的推导：设正子集 P，P-((S-P))=T ⇒ P=(T+S)/2，**奇数或越界直接返回 0**。
4. 编辑距离三操作别漏“替换”（只写增删是最常见 WA）。
5. LIS 的 O(n²) 版本 dp 含义是“以 i **结尾**”，不是“前 i 个中”。
6. 全负数组最大子数组：初始化 best=nums[0] 而不是 0。

## 练习题（附答案）

1. **为什么零钱兑换 II 外层枚举硬币、内层枚举金额？**
   答：保证同一硬币的组合只按固定顺序进入，不把 {1,2} 与 {2,1} 重复计数——这正是“组合数”。
2. **打家劫舍 II（环形）**
   答：拆两个线性问题：不偷第 0 间 / 不偷最后一间，取 max。
3. **最长递增子序列 O(n log n) 解法**
   答：tails[k]=长度 k+1 的 LIS 最小结尾（贪心），对每个数 lowerBound 替换；tails 有序 → 二分。
4. **编辑距离两个串互换了答案会变吗？**
   答：不会，dp 对称；但“只删不换”等受限版本不对称。
5. **写出 minPathSum 的一维滚动转移并说明为什么可以压缩**
   答：`dp[j] = min(dp[j](上), dp[j-1](左)) + grid[i][j]`；只依赖上一行当前列与当前行左列，一行足够。
